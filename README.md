# Trend Bot — тренды YouTube в русском сегменте стриминга

Telegram-бот, который следит за свежими видео в вашей нише (стримеры, твич-контент,
скандалы/разборки медиа-личностей) **только в русском сегменте**, считает «скорость
набора просмотров» и вовлечённость, и присылает:
- 📊 большую таблицу (100+ позиций) файлом — с анимацией появления строк
- 🚀 отдельный блок про маленькие каналы, у которых видео разлетелось непропорционально размеру
- 💡 идеи для видео + разбор паттернов подачи (форматы, вовлечённость, частые приёмы в заголовках)

**Важное ограничение:** анализ подачи строится на метаданных, которые отдаёт YouTube API
(формат Shorts/длинное видео, лайки/комментарии/просмотры, заголовок) — это не разбор
монтажа по кадрам или содержания ролика, такого YouTube API не даёт в принципе.

## Что понадобится

1. **Токен Telegram-бота** — бесплатно, за 1 минуту.
2. **Ключ YouTube Data API v3** — бесплатно, с дневной квотой.
3. Python 3.10+ на компьютере или сервере, где бот будет постоянно работать.

---

## Шаг 1. Создать Telegram-бота

1. Открой Telegram, найди **@BotFather**
2. Отправь `/newbot`, придумай имя и username (должен заканчиваться на `bot`, например `pavel_trends_bot`)
3. BotFather пришлёт токен вида `123456789:AAExampleTokenHere` — сохрани его

## Шаг 2. Получить ключ YouTube Data API

1. Зайди на [console.cloud.google.com](https://console.cloud.google.com)
2. Создай новый проект (или используй существующий)
3. В меню слева: **APIs & Services → Library** → найди **YouTube Data API v3** → нажми **Enable**
4. **APIs & Services → Credentials → Create Credentials → API key**
5. Скопируй ключ

⚠️ **Про квоту:** бесплатный лимит — 10 000 единиц в день. Один вызов `/trends` с
20 ключевыми словами (по умолчанию) тратит примерно 2000 единиц (поиск — самая дорогая
часть, 100 единиц за слово; получение статистики видео и подписчиков — дёшево).
Этого хватает на ~5 полных обновлений в день с запасом. Кэш держит данные 30 минут —
повторные вызовы `/trends`/`/idea` в этом окне квоту не тратят.
Если нужно жёстче экономить — уменьши список `DEFAULT_KEYWORDS` в `youtube_trends.py`.

## Шаг 3. Узнать свой chat_id (опционально, для авторассылки)

Если хочешь, чтобы бот сам присылал таблицу каждое утро, а не только по команде:
1. Напиши в Telegram боту **@userinfobot**
2. Он пришлёт твой `id` — это и есть chat_id

Если авторассылка не нужна — просто не заполняй `DIGEST_CHAT_ID`, бот будет работать
только по командам `/trends` и `/idea`.

## Шаг 4. Установка и запуск

```bash
# распакуй архив, перейди в папку
cd trend_bot

# создай виртуальное окружение (рекомендуется)
python3 -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate

# поставь зависимости
pip install -r requirements.txt

# настрой переменные окружения
cp .env.example .env
# открой .env текстовым редактором и вставь:
#   TELEGRAM_BOT_TOKEN — токен от BotFather
#   YOUTUBE_API_KEY — ключ из Google Cloud
#   DIGEST_CHAT_ID — твой chat_id (необязательно)

# запусти
python bot.py
```

Если всё настроено правильно, в консоли появится `Bot started. Polling...`
Иди в Telegram, найди своего бота и напиши `/start`.

## Команды бота

- `/start` — приветствие и список команд
- `/trends` — присылает файл `trends.html`: таблица 100+ видео (сортировка по скорости
  роста), сверху отдельный блок «маленький канал → большие просмотры», плюс краткая
  сводка цифрами прямо в чат
- `/idea` — сначала короткий список идей текстом в чат, затем файл `style_analysis.html`
  с разбором паттернов: % Shorts vs длинных роликов, средняя вовлечённость по HOT/RISING,
  частые слова в заголовках, детальная таблица по каждому видео

Файлы `.html` открываются в любом браузере (на телефоне тоже) — просто нажми на файл
во вложении Telegram.

## Чтобы бот работал постоянно (не только пока открыт терминал)

Локально бот перестанет работать, если закрыть терминал/выключить компьютер.
Варианты для круглосуточной работы:
- **Дешёвый VPS** (Timeweb, Selectel, Hetzner и т.д.) — залить файлы, запустить через
  `screen` / `tmux` или как systemd-сервис
- **Railway.app / Render.com** — есть бесплатные тарифы, можно задеплоить bot.py как
  Background Worker без настройки сервера вручную

## Как настроить под себя

- **Ключевые слова ниши** — список `DEFAULT_KEYWORDS` в начале `youtube_trends.py`.
  Добавляй имена конкретных стримеров/блогеров, за которыми следишь, конкретные
  инфоповоды, сленг сообщества — чем точнее слова, тем релевантнее выдача.
- **Порог "уже хайповое"** — переменная `HOT_VIEWS_THRESHOLD` (сейчас 150 000 просмотров).
- **Порог "маленький канал"** — `SMALL_CHANNEL_SUBSCRIBER_THRESHOLD` (сейчас 50 000
  подписчиков) и `SMALL_CHANNEL_VIEW_MULTIPLIER` (просмотры должны быть минимум в 5 раз
  больше подписчиков), оба в `youtube_trends.py`.
- **Глубина поиска по времени** — `LOOKBACK_HOURS` (сейчас последние 72 часа).
- **Фильтр "только русский сегмент"** — функция `is_probably_russian()` в
  `youtube_trends.py`, сейчас сравнивает долю кириллицы к латинице в заголовке.
- **Шаблоны идей** — списки `*_TEMPLATES` в `idea_generator.py`, можно дописывать свои
  формулировки под свой стиль подачи.
- **Визуал таблиц** — вся вёрстка и CSS-анимации в `report_builder.py` (`_CSS`).

## Структура проекта

```
trend_bot/
├── bot.py               — точка входа, команды Telegram
├── youtube_trends.py    — поиск видео + расчёт метрик трендовости
├── report_builder.py    — генерация анимированной HTML-таблицы (100+ строк)
├── idea_generator.py    — идеи для видео + HTML-отчёт с анализом паттернов подачи
├── requirements.txt     — зависимости
├── .env.example         — шаблон переменных окружения
└── README.md            — этот файл
```
